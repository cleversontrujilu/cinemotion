# 0.1.1 — 2026-11-10

Correções no pipeline. A API e os sites não mudaram.

### Fixes
- O deploy pelo GitHub Actions passa a ser autorizado: o role da AWS aceita o `sub` do token OIDC no formato com os ids do dono e do repositório, que é o formato enviado pelo GitHub. Os ids são imutáveis, então um repositório recriado com o mesmo nome não herda o acesso.
- O `configure-aws-credentials` foi atualizado para a v6, que roda em Node 24, porque a v4 roda em Node 20, que o GitHub está descontinuando.

### Testes
- Os testes de integração em paralelo no mesmo servidor não falham mais ao criar os roles da aplicação. Antes, duas migrations podiam criar o mesmo role ao mesmo tempo (`duplicate key` em `pg_authid`).
